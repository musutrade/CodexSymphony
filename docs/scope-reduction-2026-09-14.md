## 决定

| 事项 | 变更与理由 |
|---|---|
| 规范结构 | 主文改为 Current 0a；后期方案拆入 roadmap-specs，取消当前约束效力 |
| 23/24 章 | 实施队列引用行为，DoD 引用 A01～A13，不复制第二套规则 |

| 诊断与日志 | 固定失败事实、原文引用、六问与额度记录；复杂摘要/诊断 Agent 后置 |
