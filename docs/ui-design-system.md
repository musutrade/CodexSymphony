# UI 规范与 arc-admin 样式复用

> Current · 2026-09-15 · 健康页已移植；业务页面按各自任务验收

CodexSymphony 使用 Angular 22 与 Material 22，复用 arc-admin 的视觉语言：蓝色主操作、语义颜色、统一字体与间距、轻边框卡片、响应式页面及可见交互状态。主规格第 18 章以本文为页面视觉基线。

## 1. 来源与同步方式

来源仓库：本机 `~/arc-admin`；本次审查基线提交 `2faa1ca6c1a2b1a45956540e97e68a01532a40f7`。

| 来源文件 | 复用内容与目标 |
|---|---|
| `docs/ui-design-system.md` | 页面结构、CSS 分层、状态、响应式及无障碍规范，按本文适配本项目 |
| `frontend/src/styles/_tokens.scss` | 字体、间距、圆角、控件高度、动效、语义颜色和 Material 变量映射；引入 `web/angular/src/styles/_tokens.scss` |
| `frontend/src/styles.scss` | 提取实际需要的基础主题、焦点、页面标题、按钮、卡片、筛选和表格等共享模式，接入 `web/angular/src/styles.scss` |
| `frontend/src/app/pages/login/login.scss` | 登录卡片、表单、错误和窄屏布局；随平台登录页实现适配 |
| `frontend/src/app/layout/layout.scss` | 后续应用壳层的导航、内容区及移动端布局参考 |

实现时将所需资源纳入本仓库，保留来源、提交和适配记录；构建不能依赖本机绝对路径、软链接或另一个仓库的工作区。后续同步采用显式版本更新与差异审查，不自动追随 arc-admin 主分支。保留源文件适用的许可及版权说明。

共享变量以 `--ui-*` 为基础，通过 `--mat-sys-*` 适配 Material；公共页面模式集中维护，组件样式只写页面特有布局。引入样式前核对 mixin、字体、图标、动画和主题依赖，所需资源在本项目自包含。品牌文案使用 CodexSymphony。

## 2. 页面规则

- 一个应用级 `main`，提供跳到主要内容的链接；每页一个 `h1`，标题、说明与主要操作有固定层次。
- 内容最大宽度 1200px，桌面内边距 24px、窄屏 16px；间距采用源规范的 4px 阶梯，颜色、圆角和阴影使用语义变量。
- 数据页按标题、筛选、主内容、可选摘要排列；表格使用真实语义和 caption，窄屏局部滚动或按内容转为卡片，主要操作不依赖页面横向滚动。
- 加载、成功、空数据、失败状态明确；提交中防重复操作，错误保留上下文并提供可行的重试入口。
- 表单有可见标签和关联错误，按钮有准确名称，键盘焦点可见；状态同时使用文字，支持减少动效与强制颜色模式。
- 首次落地采用亮色主题；保留引入资源中的暗色变量不代表已交付暗色功能。暗色切换、全量视觉回归平台和业务无关的设计系统扩展仍可后置。

arc-admin 的账号管理、角色权限、MFA 和其他业务模块不因样式复用自动进入范围。登录行为统一由[日常 V1 第 6.1 节](daily-use-v1.md#61-用户名密码登录)定义。

## 3. 验收

每个页面随实现验证，不等待所有业务页完成；登录页在 M2 同认证一起验收。

| ID | 场景与通过条件 |
|---|---|
| UI01 | 在独立检出本仓库、没有 `~/arc-admin` 的环境中可构建；来源提交、移植文件及适配差异有记录 |
| UI02 | 页面使用统一字体、颜色、间距、标题、按钮和卡片模式；公共样式无页面间复制分叉，Material 状态使用同一语义变量 |
| UI03 | Desktop Chrome 与 Pixel 7 视口逐页检查，无页面级横向溢出、裁切或遮挡；导航、表单与主要操作均可用，移动触控目标不小于 40px |
| UI04 | 加载、空、失败、提交中状态可见；键盘完成主要操作；焦点、表单错误关联、landmark 和状态反馈正确，axe 检查通过并人工复核 WCAG AA 对比度 |
| UI05 | 减少动效与强制颜色模式仍可理解和操作；登录页支持密码管理器、错误反馈、会话过期后的返回流程 |

实现提交运行项目已有 lint、相关单元及浏览器测试、生产构建和要求的质量门禁，保留桌面与手机视觉复核记录。本文更新本身不代表样式或认证已实现。
