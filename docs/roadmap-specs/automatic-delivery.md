## 仍可后置

- webhook：实际轮询延迟成为问题时作为加速，保留轮询兜底。
- 跨批次可信证据缓存：验证耗时构成瓶颈且 provider 能明确身份/适用性时评估，不确定就完整执行。
- 收据式摘要、逐字节引文验证：原始日志与简单修复上下文不足时评估。
- 独立 formatter 候选来源链、自动 reviewer：有实际收益后单独实施，不阻挡自动合并。
- 全量 context digest/自动漂移重验证：出现复杂运行输入修改需求后再评估，不取代已批准版本绑定。
- 完整 RepairAttempt 框架：多个修复来源与执行者超出简单原子计数能力后评估；预算持久化和重复事件去重已属于日常要求。
