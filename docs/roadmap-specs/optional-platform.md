# 按需平台扩展候选

> Deferred: Phase 2+ · 非当前规范，无自动排期

| 能力 | 触发条件 | 最小评估方向 |
|---|---|---|
| 自然语言生成 Contract、澄清 Agent | 评审输入成为主要人工耗时 | 生成草稿，由人 Ready，不自动授权 |
| 多仓并行、公平调度 | 串行等待确实影响交付且用户改变顺序要求 | 先定义新的并发授权，再考虑容量/仓库锁 |
| 双租约、epoch、branch reservation | 多个独立进程/Worker 能同时写入 | 明确租约失效后如何阻止旧写者；不是单独加表 |
| 通用 ManagedResource/引用管理 | 多种资源及共享消费者超出唯一 Run 目录管理 | 从已出现的资源类型抽象，保留误删防护 |
| Planner、子任务依赖、Discussion | 真实大型需求拆解负担 | 草稿依赖与集成结果，不创建未经评审的自动工作 |
| 输出分页、压缩、Action Fusion | 长 Run 上下文/工具开销有测量依据 | 独立对照，记录失败与回读成本，不预设省 token 比例 |
| 只读诊断 Agent | 固定探针后仍反复需要人工诊断 | 独立预算、报告证据、无执行授权 |
| OTel/Prometheus/Grafana | 普通日志和数据库查询无法定位问题 | 按所需观测接入，不为指标数量建设平台 |
| 多 Runtime、fallback、金额预算 | 固定 Runtime/模型确有可用性或成本问题 | 固定任务对比后决定，不自动更换模型授权 |
| Remote Worker、Redis/NATS | 多机执行或事件吞吐真实出现 | 先定义凭证、失败恢复及交付一致性 |
| CLI/Unix socket、原生 TUI、SSE/PWA | Web 操作无法满足具体场景 | 独立协议与授权复核，不绕过平台请求落库 |
| 事件溯源重放、跨仓任务、自动部署 | 明确新产品需求 | 独立范围及授权，不扩大当前需求生命周期 |

参考细节保留在演进目录链接的 V9 Git 历史。没有触发条件时可以永久不实施。
